Instalação
==========

Requisitos
----------

* Moodle 4.5 LTS ou 5.3 LTS.
* PHP suportado pela sua versão do Moodle.

A partir de um arquivo ZIP
--------------------------

1. Baixe o ZIP do plugin (a pasta raiz deve se chamar ``eduplay``).
2. No Moodle, acesse *Administração do site* > *Plugins* > *Instalar plugins* e envie o ZIP.
3. Siga as etapas de atualização exibidas na tela.

A partir do Git
---------------

.. code-block:: bash

   git clone https://github.com/eduplay-moodle-suite/moodle-local_eduplay.git local/eduplay

Em seguida, abra *Administração do site* > *Notificações* para concluir a instalação. No Moodle 5.1 ou superior, o diretório de destino é ``public/local/eduplay``.
